# Astro portfolio

Single-page portfolio for Arun Kumar Bhardwaj — Astro static shell with React islands for interactive UI (theme wipe, motion, copy email).

## Commands

```bash
npm install
npm run dev      # http://localhost:4321
npm run build    # output → dist/
npm run preview  # preview production build
```

## Stack

- Astro
- React (`@astrojs/react`) for `Portfolio` + `ThemeToggle`
- Tailwind CSS v4 via `@tailwindcss/vite`
- Framer Motion, Lucide

## Deploy

Configured for Vercel (`vercel.json`: `astro` framework, `dist` output).
